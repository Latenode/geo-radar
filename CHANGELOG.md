# Changelog

## 1.0.0

Initial release.

- Weekly visibility measurement across Perplexity, ChatGPT, Claude and Gemini
- Visibility and brand knowledge kept as separate metrics
- Competitor share of voice from unbranded answers only
- Citation sources accumulated over a 28-day window
- Classic Google comparison through Serper
- Action plan generated from the measurement data
- HTML email report, Slack alert on threshold breach
- Example workbook: one finished run for a fictional brand, all names replaced
- Prompt generator: 32 measurement questions from a brand homepage
- Multi-brand by design, keyed on brand_id
- Sized for a 30-minute execution: answers capped at 150 words, one repeat per question by default, lighter web search on Claude and Gemini, and Claude on its faster Haiku model
